# Foundation Models

| Packages | Description | Paper |
|:--:|:--|:--:|
| **[MOMENT](https://github.com/moment-timeseries-foundation-model/moment)** | Open time-series foundation models from CMU/Auton Lab for forecasting, anomaly detection, classification, imputation, and embeddings. | [Paper Link](https://arxiv.org/abs/2402.03885) |
| **[IBM Granite TSFM](https://github.com/ibm-granite/granite-tsfm)** | IBM's open repository for time series foundation models, notebooks, demos, and TinyTimeMixer workflows. | [IBM Docs](https://www.ibm.com/granite/docs/use-cases/forecast-energy-demand) |
| **[Timer / Sundial](https://github.com/thuml/Large-Time-Series-Model)** | THUML repository for large generative time series models such as Timer, Timer-XL, and Sundial. | [Timer Paper](https://arxiv.org/abs/2402.02368) |
| **[OpenLTM](https://github.com/thuml/OpenLTM)** | Unified codebase for developing and evaluating large time-series models and recent LLM4TS implementations. | N/A |
|  **[Time-LLM](https://github.com/KimMeen/Time-LLM)**  | Time-LLM is a reprogramming framework to repurpose LLMs for general time series forecasting with the backbone language models kept intact.                                                                                                                                           |   [Paper Link](https://arxiv.org/abs/2310.01728)   |
|  **MOMENT**  | From CMU. A family of open-source foundation models for general-purpose time-series analysis.                                                                                                                                        |   [Paper Link](https://arxiv.org/abs/2402.03885)   |
|  **TimesFM**  | From Google. A time-series foundation model for forecasting whose out-of-the-box zero-shot performance on a variety of public datasets comes close to the accuracy of state-of-the-art supervised forecasting models for each individual dataset.                                                                                                                                           |   [Paper Link](https://arxiv.org/abs/2310.10688)   |
|  **[Lag-Llama](https://github.com/time-series-foundation-models/lag-llama)**  | A general-purpose foundation model for univariate probabilistic forecasting.                                                                                                                                              |   [Paper Link](https://arxiv.org/abs/2310.08278)   |
|  **[MOIRAI](https://github.com/SalesforceAIResearch/uni2ts)**  | From Salesforce. An encoder-only Transformer model, specialized in universal time-series forecasting.                                                                                                                                          |   [Paper Link](https://arxiv.org/abs/2402.02592)   |
|  **TimeGPT**  | The authors claim it's the first foundation model for time series forecasting.                                                                                                                                         |   [Paper Link](https://arxiv.org/abs/2310.03589)   |
|  **[Chronos](https://github.com/amazon-science/chronos-forecasting)**  | From Amazon. Chronos is a family of pretrained time series forecasting models based on language model architectures.                                                                                                                                  |   [Paper Link](https://arxiv.org/abs/2403.07815)   |
